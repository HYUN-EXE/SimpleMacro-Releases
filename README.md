# SmcR Releases

Public release repository for SmcR portable Windows packages.

SmcR is a keyboard and mouse macro utility for user-authorized desktop automation.

This repository does not contain the SmcR application source code, credentials, development environment files, or user macro data.

Release assets may include:

- `SmcR_Setup.zip`
- `SmcR_Setup.zip.sha256`

The executable is currently unsigned, so Windows SmartScreen may display a warning.
